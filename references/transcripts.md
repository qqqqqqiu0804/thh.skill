### 【事件全貌】

2026.08.17 凌晨，我私下与朋友 B、C 组队游玩游戏《无畏契约》，匹配到路人 1、路人 2。其中路人 1 为某主播，角色为暮蝶，以下称【主播】；路人 2 角色为盖可。

在发生争吵前，仅朋友 B 与其沟通，共 2 次，以下为内容——

**【沟通①】**

我方防守开局，对方实力较好，陷入逆风。盖可（即路人 2）防守 A 小压力较大，因此朋友 B 和该主播沟通，内容如下：

朋友 B：暮蝶你给个 A 小单向吧。  
主播：不是烟的问题，是你们对不过的问题。  
朋友 B：你给个 A 小单向，这样盖可好撤回来一点。  
主播：不需要撤回来，进点了我全部补完。

**【沟通②】**

多个对局后，对方进攻 B 点，我方需要 B 大的烟来延缓对方进攻，"烟"需要暮蝶来释放。

朋友 B：B 大给烟啊  
主播：给不到，懂吗？  
（沉默 5 秒）  
主播：不是，你们在叫什么啊？战绩在我下面是没资格和我说话的，懂吗？  
（此时暮蝶战绩 12-8、朋友 B 战绩 8-8）

【除此 2 段沟通外，我方和其无任何其他沟通。】

在该主播说完第 2 段话后，朋友 B 和他发生争吵，随后我与朋友 C 开麦同样与之争吵。

以上为事件情况。

## 图 2：逐点反驳 ① —— 我方 3 人率先压力他

以下针对对方主播的控诉进行回应：

**一、我方 3 人率先压力他。**

全部的沟通细节我展示在前文了。

"向烟位要烟"是这个游戏中很常规的战术沟通，在语气不卑不亢，且诉求合理的情况下，我认为这样的沟通是合理的。

沟通 1，被对方质疑后，朋友 B 也并未与其争吵，而是阐述提出诉求的原因；被拒绝后，也未进行任何表态或批评，正常进行游戏。

沟通 2，朋友 B 正常提出诉求，该主播带有一定情绪的进行回复，考虑到对局逆风，也并未有人计较语气问题，而是选择接受队友的沮丧。

然而没想到，在沉默 5 秒后，对方突然发怒了。

我个人认为，在和对方主播沟通的过程中，朋友 B 的态度始终是不卑不亢、尺度合适的。可能没有做到祈求的程度，但也绝不至于被称之"压力"。

相反，得到"不需要撤回来，进点了我全部补完""你们在叫什么？""战绩在我下面没资格和我说话"这样的反馈，我认为是有些消极交流和战绩歧视的，这个"压力"来源于谁，见仁见智。

当然只是我个人的看法，欢迎大家指正。

## 图 3：逐点反驳 ② —— 战绩不如对方主播，以下犯上

**二、战绩不如对方主播，以下犯上。**

电子竞技实力至上，战绩出色的队友有指挥全队的权利，这点我欣然接受。我也不否认，我们三个以及另位路人，打的不如该主播出色。

但是开麦沟通战术，不正是我们几个尽管实力不佳，也想争取拿下对局的体现么？如果只有战绩第一的人才有资格开麦说话，那会不会脱离了《无畏契约》这样团队游戏的初衷，有些太过严苛了？我支持游戏大神用实力让压力怪闭嘴，但如果队友正常的沟通都接受不了，会不会有些过了？

当时该主播战绩 12-8，朋友 B 战绩 8-8，差距真的有大到连"说话"都没资格吗？我们正常进行自己本段位的对局，打不过对面，就活该被游戏主播战绩歧视吗？我觉得是有问题的。

当然只是我个人的看法，欢迎大家指正。

## 图 4：逐点反驳 ③ —— 我方 3 人骂他

**三、我方 3 人骂他。**

首先，我认为不提前因后果，用行为和语言挑起对方怒火后，掐头去尾，只单拉出对方回击的行为，来指控对方欺负自己，是很离奇的一件事。更别说目前看来，似乎还有断章取义、颠倒黑白，把自己包装成一个"受尽欺负的游戏大神"的倾向。

一个团队合作游戏，没有人上来就是带着火气游玩的，像主播这样上来就消极沟通的情况毕竟是少数。队友考虑到在逆风承托你的情绪，并不是你得寸进尺挑起事端，战绩歧视的理由吧？

如果接受不了别人的情绪，请先控制好自己的情绪。

## 图 5：逐点反驳 ④ —— 我方 3 人言语粗俗

**四、我方 3 人言语粗俗。**

首先，一个满嘴 JB、TM 的主播，居然在喷完别人后，要求别人以礼相待，这点让我很吃惊。但是我还是给出回应。

朋友 B：全程与该主播就战绩问题进行互喷，重点几乎放在"含金量""简单枪""架过点""你多拿 4 个头有啥了不起的"等等话题，掺杂粗口长时间缠斗。在日常生活或直播间，我认为是爆粗口是较为低俗的行为；但在其二人互喷互骂的情况下，我难以评价，交给大家判断。

我：全程就该主播玻璃心和战绩歧视的点进行阴阳，喷了小 10 局应该连粗口都没爆过一句。最严重的话是"你在家里你妈让你干个啥事，你是不是也说战绩在你下面没资格和你说话，和你妈也这样爆了？"、"你爸在家上个厕所，你是不是也要给他底下封个烟，说战绩在你下面没资格上？"如果这两句话大家觉得尺度过大，我会进行反思。

除此之外，我认为我所有的回击，都是在互喷当中正常且尺度合适的怼人，不存在人身攻击和羞辱语言的情况，我也不会因为阴阳一个率先压力的人而致歉。

我和朋友 B 的措辞，哪怕在该主播选择性截取的片段中，也是可以体现和我以上内容保持一致的，如果对方主播有任何质疑的点，欢迎拿出证据。

## 图 6：第三方切割 —— 朋友 C

朋友 C：录音中涉及对方伴侣、生育等极端攻击性言论，由同行朋友 C 说出，并非我本人所说。我不认可这些内容，也认为无论争执因何发生，都不应使用这样的方式攻击他人，我也不会对其进行任何的偏袒和辩白。

在对方的录屏中能看见，在朋友 C 说完相关话术后，我和朋友 B 全部都沉默了。因为哪怕作为朋友，并在和外人吵架，这样的话都让人有些无法接受。我在全队麦里沉默的时候，正是在打开组队麦向朋友 C 表达"你这些太过了吧？"，这是我的态度。

我也在此严正声明：我不认可朋友 C 的所作所为。

一方面，我会重新认真审视这段关系；另一方面，朋友 C 是能够独立承担责任的成年人，相关言论应当由他本人直接向当事人道歉并承担相应责任。我会协助双方建立联系并配合；最后，若对方主播有需要，也可以拿起法律武器，控告朋友 C 的行为。我也会督促其积极承担应有的责任。

有朋友质疑，为什么你不对你朋友的行为加以制止？

首先，在此之前的对喷，还在正常的尺度内，谁都想不到朋友 C 会突然说出这样的话，无法预判。要求我在大声争吵的同时，时刻听清朋友 C 在说什么，并立刻制止，是不现实的要求。

其次，在听清他的话后，大家的沉默也可以说明一定的问题。我和朋友 B 也都第一时间在组队麦里表示了不适和过火。由于正在和对方争吵，所以没选择开全队麦，但是又的确对这段话感到反感，所以选择开组队麦的方式进行表态。我认为，这已经是当下那个时刻面对一个朋友突然无礼的行为，能做出最合理的反应了。直接当着所有争吵者的面，批判他并选择断交，不符合现实生活中社交关系的处理方式。我已经在合理限度内表达了我的不满。

至于指控我帮腔朋友 C 这段话的，这完全就是无稽之谈了。对方的录屏里也能看到，朋友 C 说完第一句后，我根本没听见他在说什么，自顾自在喷自己的东西，没对他说的话有任何接龙或帮腔，说的内容更是完全不相干；等他后面的文字接着说出来之后，我直接沉默了，更是不存在帮腔的行为，甚至还开组队麦表达了不适，这点指控，我认为是不合理的。

作为成年人，朋友 C 有义务为他自己的行为负责，我在直播间以外的地方，没有能力和资格去约束他，也无法预判他任何行为，只能说我交友眼光不慎，或者在大家都有在持续成长的岁月里，他的个人素质并没有提高到一个正常成年人应该有的水平，我很失望，我也会重新审视这段关系。但是就像我说的，除我交友选择外的事，我无法控制。如果在我的直播间，我会为其行为的连带责任道歉；但这样私下的情况，恕我无法为一个 24 岁成年人的失言而负责，因为我并不认可他这番话中的任何一个字，这是他需要自己面对和反思的错误，我也拒绝任何不必要的上升与捆绑。如果单纯因为认识，强行把朋友 C 的所作所为套在我头上，我认为是有些过度的。

## 图 8：总结

**总结：**

创作不易，我充分理解主播想抓住一切机会制造热点、获取流量的渴望。但是流量宝贵、取之有道——精品的内容创作、精湛的游戏技术能够博得更多人的喝彩，如果只依靠断章取义、颠倒黑白的手段挑起对立，这样的流量，会不会来得快、去得也快呢？

相比之下，不如认真提高自己的游戏技术，减少在开播时消极沟通、战绩歧视队友的行为。虽然不知道这是不是你的直播习惯，但我相信更多观众愿意看见一个更加阳光的你，你觉得呢？

我呼吁我的粉丝，不要因此去攻击对方，但我也呼吁对方停止这样颠倒黑白、扭曲事实的行为，不要让事情上升到法律的层面。相关直播、发言，我已经委托公司进行了取证，如有必要，我会采取对应的法律手段。

当然，如果你选择硬刚到底，欢迎你拿出你的直播录屏，把完整版呈现在网友们的面前，让大家来评价孰是孰非——希望你有这份底气。

朋友 C 与对方主播的后续进展，若有更新我会向大家同步。

最后，我再次明确声明，我本人不欠对方主播任何道歉与经济赔偿，我也拒绝任何形式的道德绑架、捆绑、无端上升。如果要我道歉，我只会向我的观众说声不好意思，因为这件事让大家跟着担心或者难过，我的确考虑的不够周到。作为主播，我私下游玩被队友压力、辱骂，大多情况不再回应，就是考虑到了这方面的影响。然而这次遇上这样消极沟通后还要战绩歧视队友的情况，的确是没有选择佛系，选择了对呛，是我忍功不够。尽管我的语言克制在合理尺度内，但可能还是得更加温柔一些、耐心一些。给大家添堵了，抱歉。

至于朋友 C，首先，他不会再在任何我的社交媒体之中出现；其次，由于他在我们直播间出现过过，不管他骂的对象是谁，都需要为自己粗俗的语言向直播间的观众道歉，这是一种情感伤害。我会让他以手写、阅读的方式录制完毕，发布在合适的账号。这同时也是一个非常典型的反面案例，也希望所有了解到此次事件的朋友，因此而意识、唾弃这种行为。

以上就是事件的全貌，以及我的回应及看法，不可避免一些观点可能有我主观的成分影响，恳请大家指正、讨论。但我再次声明，我拒绝一切以道德绑架、捆绑、无端上升为手段的控诉，也不会纵容、认可通过断章取义、颠倒黑白的方式，引导对立的主播。我的体量更大，并不是我需要配合、忍受这种行为的理由。对方目前开始公开对我粉丝个人主页进行直播点评，我更会严肃取证协助粉丝处理，希望对方同为有粉丝的主播，有一定的底线与操守。

最后还是向我的观众说声不好意思，是我考虑不周，抱歉。是非对错，由大家评说，我只负责做好我的本职工作，不再配合对方及任何人无聊的文字游戏，谢谢各位。
