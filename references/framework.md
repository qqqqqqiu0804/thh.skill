# PR 公文框架详解（pr-statement-writer 配套参考）

本文件提供：① 两种体裁的**填空模板**；② 真实样本的**逐段注解**（说明"为什么这么写"）；③ **常用句式库**；④ **反模式（禁忌）**。

> 用法：写稿前先读"填空模板"，按用户事实填；卡壳时查"句式库"；写完过"反模式"自查。如需对照原文，见 `transcripts.md`。

## 一、A 型 · 危机回应 / 反击声明（填空模板）

```
【开场定调 + FAQ 辟谣】
各位好，就 [事件/对方在X的控诉]，我统一回应如下：
先就流传较广的几点传闻做澄清（是/否）：
1. [传闻A]？——否。
2. [传闻B]？——否。
（原则：先否定最夸张的传闻，把事态压回"没那么离谱"的基线）

【事件全貌】
[客观、按时间线叙述事件经过，不急于自证，先铺事实基线]

【逐点反驳】（每条：重述对方说法 → 反驳+反证）
针对 [对方主播] 提出的主要控诉，逐一说明：
控诉1：[对方说法] → [我方事实/语境化反驳]
控诉2：[对方说法] → [我方反驳；可承认可控小错"言语过激"但否认核心指控]
……

【第三方切割】
关于 [朋友C/团队/粉丝] 的 [具体行为]，其言论不代表我，[其自行承担相应责任]；
但我也拒绝因 [第三方] 的行为，对我本人做过度捆绑、上升与道德绑架。

【反制：我的反问 + 诉求清单】
对此我有几点疑问：[反问1]？[反问2]？……
我方诉求（具体、可验收）：
1. 删除 [恶意剪辑/不实视频]
2. 就 [具体行为] 公开道歉
3. 停止 [带节奏/引导对立] 的行为
4. [经济赔偿 / 其他]
（诉求需绑定"公司/我已完整取证"做背书）

【总结收束】
呼吁大家理性看待，[之后非必要不再参与骂战]，我只需完成好本职工作。
```

## 二、B 型 · 退场 / 告别声明（填空模板）

```
【柔和开场】
大家好，今天发文想和大家打几个招呼。

【护粉优先】（最重要，前置）
首先也是最重要：希望大家 [别发帖/评论为我发声表态]。
不同的声量站在我这边是好事，但这个节点支持我容易收到激烈反驳甚至人身攻击，
所以更希望大家先保护好自己。有关我的批评，合理的部分由我自己承担、反思；
需要帮助的朋友，请联系 [助理/通道]，我们会第一时间提供帮助。

【恳请外界】
也恳请各位网友，把所有的批评与不满发送给我本人（评论/私信不关），
[我的粉丝/支持者] 只是普通网友，彼此不存在仇恨，没必要攻击他们。

【自我剖白】
关于"我是一个什么样的人"，这是很主观的事。
我曾努力自证"不是坏人"，后来发现没有标准答案——
[有人觉得你X是好人，有人觉得你Y是坏人]。
我的所作所为构成一个完整的我，我不再试图说服任何人。

【退场决定 + 原因 + 安排】
我打算离开互联网 [一段时间/暂停营业]。
原因：[状态出现问题/需要沉淀/不快乐不足以创造快乐]。
实际上我已推掉 [具体时段] 的工作，除 [必要陪伴/直播] 外给自己一段调整时间。

【感情 + 祝福收尾】
最放不下的是喜欢我的大家，但离开也是很难的决定，希望你们不要怪我。
如果喜欢我让你不快乐，我更希望你去追属于自己的快乐。
无论你留下、离开、喜欢或憎恨，我都在这里默默祝福你。
```

## 三、真实样本逐段注解

### 样本 1：A 型危机回应（桃黑黑Tor 2026.08 无畏契约对局纠纷回应）

详见 `transcripts.md` 完整原文。以下为逐段技法注解：

- **FAQ 辟谣前置**：6 个"是/否"快问快答——"是否和朋友先压力对方：否""朋友是否代表我的立场：否""是否认可朋友的行为：否"。作用：先把"率先挑事""认同极端言论"等最耸动的帽子摘掉，让后续叙述落在"没那么离谱"的基线。
- **事件全貌**：按时间线铺"沟通①→沟通②→争吵"，并标注"除此 2 段沟通外，我方和其无任何其他沟通"。技法：**先给事实框架，不急着喊冤**，让读者自己判断因果。
- **逐点反驳**：对 4 条控诉分别重述 + 反驳 + 反证。
  - 对"率先压力"：用"向烟位要烟是常规战术沟通"把行为合理化为正常游戏沟通；用对方原话"战绩在我下面没资格和我说话"反证压力来源在对方。
  - 对"言语粗俗"：策略性让步——"如果这两句话大家觉得尺度过大，我会进行反思"，但紧接否认核心指控："不存在人身攻击和羞辱语言的情况，我也不会因阴阳一个率先压力的人而致歉"。
- **第三方切割（朋友 C）**：三层递进——
  1. "由同行朋友 C 说出，并非我本人所说"（事实切割）；
  2. "我不认可这些内容""不会对其进行任何偏袒和辩白"（态度切割）；
  3. "朋友 C 是能够独立承担责任的成年人""恕我无法为一个 24 岁成年人的失言而负责""拒绝任何不必要的上升与捆绑"（责任边界切割）。
- **反制反问 + 诉求清单**：5 个反问聚焦"为何只展示部分录屏""是否敢拿全局录屏""是否扭曲受害者形象"；5 项诉求具体可验收：经济赔偿拒绝、本人道歉拒绝、朋友 C 道歉可协助建联、法律手段可协助、要求对方向游戏玩家道歉。
- **总结收束**：双轨并行——对外"呼吁粉丝不要攻击对方，但要求对方停止颠倒黑白"，对内"向观众说声不好意思，是我考虑不周"；最终以"我只负责做好我的本职工作，不再配合对方及任何人无聊的文字游戏"主动结束话题。


### 样本 2：B 型退场声明（宣布离开互联网一段时间）

- **护粉前置**：开篇第一段就恳请粉丝"别为我出头"，把批评收口到自己身上——和 A 型"收口矛盾于自身"同源。
- **恳请外界别伤第三方**：反复强调粉丝"只是普通网友""认真生活的普通人"，把对立情绪降温。
- **自我剖白不自证**：直接宣告"不再试图说服任何人""我是什么样的人取决于你怎么看"——放弃自证陷阱，反而显成熟。
- **退场原因 + 实际安排**：给出具体时段（推掉8月中-10月底工作）、具体状态（不快乐/需沉淀），**越具体越可信**，避免"我累了"这种空话。
- **感情 + 祝福收尾**：不舍但祝福，给受众"冷静审视关系"的空间，主动结束话题，塑造"体面退场"姿态。

## 四、常用句式库（按功能取用）

**切割 / 划边界**
- "我仅对 [我自己的言行] 负责，[第三方] 的行为由其自行承担。"
- "拒绝就 [他人行为] 对我本人做过度的捆绑、上升与道德绑架。"
- "[第三方] 是能够独立承担责任的成年人，相关言论应当由他本人直接向当事人道歉并承担相应责任。"
- "我交友眼光不慎，但除我交友选择外的事，我无法控制。"

**占领道德高地（标签化对方，勿人身攻击）**
- "不认同任何通过 [颠倒事实/断章取义] 来 [引导对立/攫取流量] 的行为。"
- "正告对方立即停止以 [歪曲事实/引导对立] 等手段博取流量。"
- "如果只依靠断章取义、颠倒黑白的手段挑起对立，这样的流量，会不会来得快、去得也快呢？"
- "相信更多观众愿意看见一个更加阳光的 [对方身份]，你觉得呢？"

**收口矛盾于自身**
- "有任何不满，直接发给我本人，评论和私信都不会关闭。"
- "喜欢我的人能过得好，就是对我最大的支持，切记不用为我说话。"
- "我呼吁我的粉丝，不要因此去攻击对方。"
- "如果要我道歉，我只会向我的观众说声不好意思，因为这件事让大家跟着担心或者难过。"

**反制 / 取证背书**
- "公司已完成完整取证，若继续变本加厉，将采取法律手段追究到底。"
- "就 [具体行为]，要求 [删除/道歉/赔偿]，否则 [法律途径]。"

**缓冲 / 留退路**
- "目前 / 可能 / 一段时间 / 非必要"
- "当然只是我个人的看法，欢迎大家指正。"
- "如果这两句话大家觉得尺度过大，我会进行反思。"
- "不可避免一些观点可能有我主观的成分影响，恳请大家指正、讨论。"
- "之后非必要，不再就此事进行或参与任何回复与骂战。"

**收束姿态**
- A 型："是非对错，由大家评说，我只负责做好我的本职工作，不再配合对方及任何人无聊的文字游戏。"
- B 型："无论你做出什么选择，我都会在这里默默祝福你。"

## 五、反模式（绝对禁忌）

1. **点名开战**：直呼对方真名/账号并正面辱骂 → 会被截图成"主动挑事"。改用"某主播/对方"。
2. **脑补事实**：用户没给的证据/时间线，AI 自行编 → 一旦与真实不符，声明瞬间崩盘。存疑处显式标注。
3. **情绪化人身攻击**：用脏话/侮辱替代论证 → 丢掉道德高地，授人以柄。
4. **空口威胁**："再这样我就不客气了"但无"已取证/法律"背书 → 不可信。
5. **不切割**：把"朋友的错"和"我的错"混为一谈，或反过来被无限连带 → 要么背锅要么甩锅都难看。
6. **把话说死**："永远不再播""绝对没说过"等不可撤回断言 → 留回旋余地是公关基本功。
7. **结构混乱**：一段到底、不分点 → 读者抓不住重点，显得心虚。
8. **自证陷阱**：B 型里拼命解释"我不是坏人" → 越描越黑；正确做法是宣布"不再自证"。

## 六、完整成稿示范（虚构示例，演示生成结果）

> 以下为用本框架生成的**虚构示例**，仅演示成稿形态，不代表真实事件。对比 `transcripts.md` 的真实原文，可感知"模板 → 成品"的落点差异。

**输入（用户提供的料）**：小博主"阿照"被大 V"老周"在直播中点名"抄袭创意、恶意蹭热度"，阿照要发 A 型危机回应，语气克制、有创作记录可证清白、粉丝别去对线。

**【成稿】**

各位好，就老周在直播间对我提出的"抄袭创意、恶意蹭热度"等相关控诉，我统一回应如下。

先把流传较广的几点说法做澄清：
1、是否抄袭老周创意？——否。
2、是否主动蹭对方热度？——否。
3、是否认可团队伙伴在评论区的过激发言？——否。

【事件全貌】
X 月 X 日，我独立完成了作品《[作品名]》，从选题到成片的全过程均有创作记录与工程文件可查。老周所称"高度雷同"的部分，属于我所在赛道通用的常规手法，并非其独创。

【逐点反驳】
一、关于"抄袭"。我的创作时间线早于老周发布时间，草稿与工程文件均可作证；老周未展示完整对比，只截取外观相似的片段，这是典型的断章取义。
二、关于"恶意蹭热度"。我方账号体量远小于对方，并无蹭之必要；所谓"蹭"，实为对方主动点名带来的被动流量。

【第三方切割】
团队伙伴小 K 在评论区情绪激动的发言，不代表我的立场，小 K 会自行承担相应责任；但我拒绝因小 K 的言论，对我本人做过度的捆绑与道德绑架。

【反制：反问 + 诉求】
我有几点疑问：为何不展示完整的创作时间线？是否敢放出双方工程文件，供网友公正评判？
诉求如下：停止以"抄袭"定性并公开误导；如继续，我已委托完成取证，将采取相应法律手段。

【总结】
我呼吁我的粉丝，不要因此去攻击对方；但我也正告对方停止颠倒黑白、扭曲事实。是非对错由大家评说，我只负责做好我的本职工作。谢谢大家。

**【成稿说明】**
- 缓冲词："所谓'蹭'""典型的断章取义""被动流量"——保留可显克制，删掉则更硬。
- 必须用户核对：`[作品名]`、X 月 X 日具体日期、创作记录/工程文件是否真实存在（这是核心证据，缺失则"可证清白"站不住）。
- 存疑未核实：老周"主动点名"的具体直播时间，若用户未提供，建议补一句"据我所知"或直接引用已知片段，避免无据断言。
