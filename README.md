# thh.skill

一个 WorkBuddy 用户级 Skill：**公关公文写作（pr-statement-writer）**。

从用户自己的事件经过 + 想表达的意思，**一步直接生成一篇可发布的危机回应 / 退场声明**，而不是只给模板。

语料来源：微博用户「桃黑黑Tor」公开的两类公关长文 —— ①《无畏契约》纠纷的详细危机回应（8 张长图）；② 离开互联网的退场声明。经截图转文字 + 横向拆解，提炼出可复用的六段式骨架、共享修辞原则与填空模板。

## 目录结构

```
SKILL.md                 # 技能入口：触发条件、生成模式 Workflow、共享原则、两型骨架
references/
  framework.md           # 详细填空模板 + 真实样本逐段注解 + 句式库 + 反模式 + 完整成稿示范
  transcripts.md         # 8 张长图声明的完整原文（截图转文字实录）
corpus/                  # 原始语料：8 张微博长图 JPG
```

## 两种体裁

- **A 型 · 危机回应 / 反击声明**：被指控、被造谣、需逐条反驳并提诉求。
- **B 型 · 退场 / 告别声明**：状态不佳、决定暂停营业或离开平台，需安抚受众并收尾。

两型共享同一套声音与修辞技术：切割（我/朋友/粉丝/公司各担各责）、收口矛盾于自身、占领道德高地、不点名升级、策略性让步、留退路、反制绑定取证。

## 安装

把本仓库根目录（含 `SKILL.md`、`references/`）复制到 WorkBuddy 的 skills 目录：

```
~/.workbuddy/skills/pr-statement-writer/
```
